## 11. CLI status 与 REST status 差异说明 + fuma service（2026-11-15 02:35，v1.0.9）

- CLI `fuma system status` 在**一次性 CLI 进程**内执行 dispatch，因此 `pid`/`uptimeSeconds` 是 CLI 进程自身（通常 uptime=0，pid 每次都不同）。
- REST `GET /v1/status` 由常驻 daemon 处理，`pid`/`uptimeSeconds` 才是 systemd 服务进程；其余字段（DB/账号/outbox/对账）两者读同一 SQLite，内容一致。
- 新增 `fuma service status` / `fuma service health`：直接访问运行中的 REST 服务（默认读取 config 的 host/port/apiToken），用于查看 daemon 状态。
- 能力描述已补充说明；运维手册/快速开始/README 增加 `fuma service` 用法。
